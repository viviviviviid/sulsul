## 번역 시작과 이어 읽기

웹페이지에서 **우클릭 → 술술 번역** 또는 **확장 아이콘 → 번역 시작**을 누르세요. 원문 언어는 자동으로 판단하고, 설정에서 선택한 언어로 번역합니다.

한 번 켜면 같은 탭·같은 사이트의 다음 페이지와 새로 나타나는 글도 자동으로 번역합니다. 현재 화면과 바로 아래 내용을 먼저 읽고, 더 먼 글은 스크롤로 가까워질 때 번역합니다. 다른 탭을 보는 동안에는 새 요청을 멈추며 돌아오면 이어갑니다.

처음 팝업을 열면 단축키 사용 여부를 선택할 수 있습니다. 팝업의 **단축키**에서 Chrome 설정을 열고 **술술 실행**에 원하는 키를 배정하세요. 팝업에서 안내하는 키는 **Alt + Shift + S**입니다. 다른 확장과 겹치면 다른 키를 선택할 수 있습니다. 시작 동작을 반복해도 번역 버튼이나 작업이 중복 생성되지 않습니다.

## 읽는 중 조작하기

페이지 모서리의 술술 버튼에 커서를 올리면 조작 버튼이 나타납니다.

| 버튼 | 동작 |
| --- | --- |
| 일시중지 | 자동 번역을 멈추고 지금 화면을 유지합니다. |
| 이어 읽기 | 멈춘 번역을 이어갑니다. |
| 원문 보기 | 자동 번역을 멈추고 원문으로 돌아갑니다. |
| 종료 | 원문으로 돌아가고 술술 버튼을 닫습니다. |
| 숨기기 | 번역을 계속하면서 버튼만 숨깁니다. 작은 표시를 눌러 다시 엽니다. |
| 설정 | 번역을 유지한 채 설정 페이지를 엽니다. |

버튼을 드래그하면 네 모서리로 옮길 수 있습니다. 확장 아이콘의 팝업에서도 현재 번역 상태를 확인하고 일시중지·원문 보기·번역 종료를 선택할 수 있습니다.

예시 문서와 미리 준비한 번역·연결 상태로 촬영한 실제 확장 화면입니다. AI 번역 품질이나 속도를 측정한 화면은 아닙니다.

## 문단의 원문 확인하기

번역된 글자에 커서를 잠깐 올리면 그 문단의 원문을 볼 수 있습니다. 링크나 코드로 나뉜 조각도 문단 단위로 합쳐 보여줍니다. 원문을 선택·복사하거나 긴 내용을 스크롤할 수 있고, Esc로 닫습니다.

설정의 **원문 툴팁**에서 켜고 끌 수 있습니다. 기본값은 켜짐이며 변경하면 열린 페이지에 바로 적용됩니다. 원문 확인에는 추가 AI 요청이 없습니다.

## 언어·모델·버튼 설정

설정에서 한국어·영어·일본어·중국어(간체/번체)·스페인어·프랑스어·독일어를 선택할 수 있습니다. 설정 화면은 현재 한국어입니다.

기본 모델은 **자동 · 계정 기본 모델**이며 Fast 모드는 꺼져 있습니다. 모델 목록에서 고르거나 **직접 입력**으로 모델 ID를 지정할 수 있습니다. 목록은 계정에서 조회한 결과가 아니며, 실제 사용 가능 여부는 번역할 때 확인됩니다. **연결 확인**은 로그인 상태만 확인합니다.

**Fast 모드**를 켜면 지원 모델에서 속도가 빨라지는 대신 사용량이 더 차감됩니다. 모델·Fast 설정을 저장하면 기존 번역을 원문으로 돌리고 일시중지하므로 페이지에서 **이어 읽기**를 누르세요. 계정의 Codex 이용 한도를 사용하며 API 키 연결이나 유료 API 자동 전환은 제공하지 않습니다. [계정·모델·Fast 안내](providers.md)

**네비게이션 버튼 모션**에서는 모두 섞기·장난꾸러기·빙글빙글·접었다 펴기·숨 고르기·잔물결·정지 중 선택할 수 있습니다. 미리보기를 보고 고르면 번역을 멈추지 않고 열린 페이지에 바로 적용됩니다. 모션과 미리보기는 AI를 사용하지 않습니다.

## 사용 기록 보기

팝업의 **사용 기록** 또는 **설정 → 기록 보기**에서 날짜·모델별 사용량과 요청 결과를 확인하고 CSV로 내려받을 수 있습니다.

- 날짜별 추이(오늘은 시간별), 모델·사이트·Fast 설정·요청 종류별 비교, 완료·실패·취소 비율을 차트로 볼 수 있습니다.
- 전체·입력·출력 토큰, 요청 수, API 환산액, 평균 처리 시간을 선택해 봅니다. 토큰은 AI가 처리한 텍스트의 양을 나타내는 단위입니다.
- 차트와 내역에는 같은 기간·모델 필터가 적용됩니다. 확인되지 않은 값은 합계·평균에서 제외합니다.
- **API 환산액은 실제 청구액이 아닙니다.** 공개 API 단가로 계산한 USD 참고치이며, 술술은 계속 Codex 구독 한도를 사용합니다. 공개 단가나 토큰 정보가 없는 요청의 비용은 추정하지 않습니다.
- 계정의 남은 한도나 다른 앱에서 쓴 사용량을 보여주는 기능은 아닙니다. 기록 조회·차트·내보내기는 AI를 호출하지 않습니다.

기록은 이 PC에 최근 30일·최대 1,000건 보관하며 사용 기록 화면에서 지울 수 있습니다. 본문·번역문·전체 URL·계정 정보는 기록하지 않습니다. 이전 버전의 로그인·연결 확인 기록은 남아 있을 수 있지만, 0.12.3부터 이 과정에서는 AI를 호출하지 않습니다.

**이전 요청과 겹침**은 보관 중인 기록에서 같은 원문·문맥·모델 설정으로 다시 요청된 문단 수입니다. 재시도나 저장된 번역 삭제 후에도 겹칠 수 있으므로 곧바로 오류를 뜻하지 않습니다. 업데이트 이전 기록은 비교할 수 없습니다. 개발 시 비교 방법은 [구조 설명](architecture.md#반복-요청-진단)을 참고하세요.

## 저장된 번역

같은 글을 다시 읽으면 저장된 번역을 재사용하고, 바뀐 문단은 새로 요청합니다. 메뉴는 같은 출처의 다른 페이지에서도, 본문은 같은 문서·제목·절 안에서 재사용합니다. 번역 언어·모델·Fast 설정별로 구분합니다.

번역은 이 Chrome 프로필에 약 3MB·최대 1,500항목까지 보관하며 오래된 항목부터 지웁니다. 직접 지우려면 **설정 → 저장된 번역 → 지우기**를 누르세요. 저장된 결과를 재사용할 때는 AI 요청이 추가되지 않습니다.

사용 기록의 **캐시 읽기**는 AI 서버가 반복 입력을 재사용한 양으로, Chrome에 저장된 번역과는 별개입니다. 0이면 해당 요청에서 캐시 읽기가 보고되지 않은 것이며, Input 합계에는 캐시 입력도 포함됩니다. 캐시가 사용됐다는 사실만으로 구독 한도의 절감률을 계산할 수는 없습니다.

## 번역이 안 될 때

실패한 문단은 원문을 유지합니다. 오류 안내나 문단의 **!** 표시에서 원인을 확인하고 다시 시도하세요. PDF·이미지·iframe·입력창·Chrome 내부 페이지는 지원하지 않습니다. Chrome 기본 번역은 끄고 사용하세요.

연결 프로그램을 찾지 못하거나 업데이트 후 작동하지 않는다면 [설치·업데이트·문제 해결](installation.md)을 확인하세요. 데이터 전송·보관·삭제에 관한 내용은 [개인정보 안내](../PRIVACY.md)에 있습니다.
