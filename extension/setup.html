처음 한 번만 연결해요.

Chrome 확장과 이 PC의 연결 앱을 설치하면 준비가 끝납니다.

  1. 설치 파일 다운로드: Apple Silicon Mac은 Sulsul-Mac-arm64 ZIP을 풀고 술술 설치.app을 여세요. Windows는 Windows ZIP과 Node.js LTS를 설치한 뒤 install.cmd를 실행합니다.
  2. Chrome 주소창에 chrome://extensions 입력 → 개발자 모드 → 압축해제된 확장 프로그램 로드. Mac 설치 앱이 안내하는 폴더 또는 Windows ZIP의 extension 폴더를 선택하세요.
  3. ChatGPT 연결을 누르고 공식 로그인 창에서 로그인하세요. 필요한 연결 프로그램은 처음 한 번 자동으로 다운로드합니다.
  4. 웹페이지에서 우클릭 → 술술 번역을 누르세요. 단축키는 Alt + Shift + K, Mac은 Option + Shift + K입니다.

Chrome 웹 스토어 버전은 아직 없습니다. Mac 설치 앱은 초기 배포로 Apple 개발자 서명·공증이 없어 macOS의 실행 확인이 필요할 수 있습니다. 로그인·번역은 터미널 창 없이 동작합니다.

번역과 데이터

ChatGPT 연결을 통해 번역 대상 텍스트와 문맥·제목·주소를 OpenAI에 전송합니다. 번역 결과는 Chrome에 저장합니다. 계정의 Codex 이용 한도가 적용됩니다. 로그인 확인도 짧은 번역 요청 한 번을 포함합니다.

PDF·이미지·iframe·입력창은 번역 대상이 아닙니다. Chrome 기본 번역은 끈 상태로 사용하세요.
