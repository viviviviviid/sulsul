시작하기

연결은 한 번만. 이후에는 읽을 페이지에서 실행하세요.

  1. 연결 프로그램 설치

    설치 파일 다운로드 ↗

    Windows

    Node.js 22 이상을 설치한 뒤 Windows ZIP을 풀고 install.cmd를 실행하세요. 폴더는 이동하거나 삭제하지 마세요.

    Node.js 다운로드 ↗
    Mac · Apple Silicon

    Mac-arm64 ZIP을 풀고 술술 설치.app을 실행하세요. Node.js는 따로 설치하지 않아도 됩니다.

    현재 설치 앱은 Apple 서명·공증이 없어 macOS에서 실행 확인이 필요할 수 있어요.

  2. ChatGPT 로그인

    OpenAI 공식 화면에서 로그인해요. 계정의 Codex 이용 한도가 적용됩니다.

    ChatGPT 연결 →
  3. 읽을 페이지에서 실행

    우클릭 → 술술 번역, 또는 확장 아이콘 → 번역 시작.

    실행 단축키는 확장 팝업에서 선택해 설정할 수 있어요.

읽는 중에는

페이지의 술술 버튼에 커서를 올리면 조작 버튼이 나타나요.

  • 일시중지 — 번역을 멈추고 지금 화면 유지
  • 원문 보기 — 자동 번역을 멈추고 원문 복원
  • 종료 — 원문으로 돌아가고 술술 버튼 닫기
  • 숨기기 — 번역은 계속, 작은 표시로 다시 열기

같은 탭·사이트의 다음 페이지도 자동 번역합니다. 버튼을 드래그하면 모서리에 놓을 수 있어요. 번역 문제는 문단의 ! 표시를 눌러 확인하세요.

작동하지 않을 때

확장 목록에서 술술을 새로고침한 뒤 웹페이지도 새로고침하세요. 단축키가 안 되면 팝업의 단축키 설정에서 실제 배정 여부를 확인하세요.

PDF·이미지·iframe·입력창·Chrome 내부 페이지는 지원하지 않습니다.

확장을 처음 추가하거나 업데이트할 때

현재는 개발자 모드 설치 방식입니다. Chrome의 chrome://extensions에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램 로드’로 설치 폴더의 extension을 선택하세요.

업데이트는 새 파일을 기존 폴더에 덮어쓰고 설치 프로그램을 다시 실행한 뒤, 확장과 웹페이지를 새로고침하세요.

저장소를 직접 받아 사용한다면

소스를 내려받고 npm ci 후 Windows는 install.cmd, Mac은 bash install.command를 실행합니다. Chrome에는 소스의 extension 폴더를 로드하세요. 개인 사용에는 GitHub 포크·스토어 등록·웹 서버 배포가 필요 없습니다.

소스 설치·업데이트 가이드 ↗

스토어 공개 후 설치한다면

제작자가 제공한 스토어 링크로 확장을 설치한 뒤, 같은 배포자가 해당 스토어용으로 제공한 PC 연결 프로그램을 설치하세요. 개발자 모드나 extension 폴더 로드는 필요 없습니다. 설치 앱이 폴더 로드를 안내하더라도 건너뛰고 ChatGPT를 연결하면 됩니다.

현재는 스토어 설치 링크가 없습니다. 포크 제품은 해당 배포자의 확장과 연결 프로그램을 함께 사용하세요.

업데이트·문제 해결

읽기를 종료하고 Chrome을 완전히 닫은 뒤 새 연결 프로그램을 설치하세요. ZIP·소스 사용자는 Chrome을 다시 열어 확장과 읽던 웹페이지를 새로고침합니다. 스토어 확장은 Chrome이 업데이트하지만 PC 연결 프로그램은 자동 갱신되지 않습니다.

연결 프로그램을 찾지 못하면 같은 배포자의 설치 파일을 다시 실행하세요. 모델 오류는 기본 모델로 저장 후 연결 확인을 실행합니다. 설치 경로를 바꿀 때는 아래 가이드를 확인하세요.
