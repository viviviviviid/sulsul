처음 한 번만 연결해요.

Windows 또는 macOS의 Chrome에서 사용할 수 있습니다.

  1. Node.js LTS를 설치하세요.
  2. 술술 폴더에서 Windows는 install.cmd, macOS는 터미널에서 bash install.command를 실행하세요. Mac에서는 Apple Command Line Tools도 필요합니다.
  3. Chrome 확장 프로그램 목록에서 개발자 모드를 켜고 술술의 extension 폴더를 로드하세요.
  4. AI 선택 · 설정에서 AI를 선택하고 저장하세요. API는 본인의 키가 필요합니다.
  5. Google 연결은 공식 로그인 창에서 완료한 뒤 Antigravity 입력란에 /quit을 입력하세요. 이후 번역할 때는 터미널을 켜둘 필요가 없습니다.
  6. 웹페이지에서 쉽게 읽기 또는 Alt + Shift + K (Mac: Option + Shift + K)를 누르세요.

설치 파일에 있는 설치안내.txt에 업데이트·삭제·오류 해결 방법이 있습니다. 설치 폴더를 이동했다면 운영체제에 맞는 설치 프로그램을 다시 실행하세요.

번역과 데이터

선택한 AI에 페이지의 번역 대상 텍스트와 문맥·제목·주소를 전송합니다. API 키는 운영체제 보안 저장소를 이용해 암호화하고 번역 결과는 Chrome에 저장합니다. 팝업에서 저장된 번역을 지울 수 있어요. API 사용량 요금은 소비자용 구독과 별도입니다.

PDF·이미지·iframe·입력창은 번역 대상이 아닙니다. Chrome 기본 번역은 끈 상태로 사용하세요. 사이트 구조에 따라 일부 글이 원문으로 남을 수 있습니다.
