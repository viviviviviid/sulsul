기록과 비용은 어떻게 계산하나요?
  • 이 PC의 술술 연결 프로그램에서 최근 30일·최대 1,000건을 보관합니다. 이전 사용량은 복원하지 않습니다. 계정 전체나 다른 앱의 사용량은 포함하지 않습니다.
  • 한 요청은 여러 문단을 묶은 번역일 수 있습니다. 저장된 번역을 재사용하면 AI를 호출하지 않아 기록에도 추가하지 않습니다. 이전 버전에서 발생한 로그인·연결 확인 번역은 별도로 표시합니다. 0.12.3부터 로그인·연결 확인은 AI를 호출하지 않아 사용 기록에 추가되지 않습니다.
  • 입력 토큰에는 AI 캐시 읽기·쓰기 토큰이, 출력 토큰에는 추론 토큰이 포함됩니다. 세부 항목을 합계에 다시 더하지 않습니다.
  • 토큰을 전달받지 못하면 ‘미확인’으로 남깁니다. 실패·취소된 요청도 토큰을 사용했을 수 있습니다. 합계는 확인된 기록만 더한 값입니다.
  • API 환산액은 2026-09-09 확인한 공개 단가를 기록 시점에 적용합니다. 기본 모델 이름과 Fast 설정, AI 캐시 읽기·쓰기를 반영합니다. 실제 적용 여부가 확인되지 않은 Fast는 설정값 기준입니다. Spark·미등록 모델·모델 전환·입력 272K 초과 등 산정할 수 없는 요청은 비용을 표시하지 않습니다. 할인·세금·환율은 반영하지 않습니다. 공식 API 단가
  • 문서 본문·번역문·페이지 제목·전체 주소·로그인 정보는 기록하지 않습니다. 사이트 도메인만 저장합니다.
