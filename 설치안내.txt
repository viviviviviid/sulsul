술술 — AI 웹 번역기 0.14.5

설치 방식 선택
현재는 Releases ZIP과 소스 설치를 제공합니다. Chrome 웹 스토어 링크는 아직 없습니다.
어떤 방식이든 Chrome 확장 + PC 연결 프로그램 + 본인 ChatGPT 계정이 필요합니다. 별도 웹 서버나 공용 API 키는 필요하지 않습니다.
스토어 공개 후에는 스토어에서 확장을 설치하고 같은 배포자의 스토어용 PC 연결 프로그램을 설치합니다. 개발자 모드나 extension 폴더 로드는 건너뜁니다.
소스 직접 사용은 npm ci 후 운영체제별 설치 스크립트를 실행하고 extension 폴더를 로드합니다. 개인 사용에는 포크나 스토어 등록이 필요 없습니다.
상세 설치·업데이트·삭제: docs/installation.md
그대로 재배포 또는 독립 포크·스토어 배포: docs/publishing.md

Windows ZIP
1. Node.js 22 이상의 LTS를 설치합니다: https://nodejs.org/en/download
2. ZIP을 보관할 폴더에 풀고 install.cmd를 실행합니다.
3. Chrome 주소창에 chrome://extensions 입력 → 개발자 모드 → 압축해제된 확장 프로그램 로드 → extension 폴더를 선택합니다.
4. 술술의 ChatGPT 연결을 누르고 공식 로그인 창에서 로그인합니다. 첫 연결은 공식 Codex 다운로드가 필요합니다.
5. 읽을 페이지에서 우클릭 → 술술 번역을 누릅니다.

Mac ZIP
macOS 13.5 이상인 Apple Silicon Mac은 Mac ZIP의 술술 설치.app을 열고 안내를 따르세요. Node.js와 개발 도구를 따로 설치할 필요가 없습니다.

Chrome 120 이상이 필요합니다. 확장 목록에는 술술 — AI 웹 번역기로 표시되며 우클릭 메뉴는 술술 번역입니다.

다음 실행
PC를 다시 켜도 터미널이나 연결 프로그램을 직접 실행할 필요가 없습니다. 로그인 만료 시 ChatGPT 연결에서 다시 로그인하세요.

업데이트
Windows는 새 버전의 파일을 기존 설치 폴더에 덮어쓰고 install.cmd를 다시 실행합니다. Mac 설치 앱 사용자는 새 Mac ZIP을 풀고 술술 설치.app을 다시 실행합니다. 소스 설치는 git pull --ff-only와 npm ci 후 설치 스크립트를 다시 실행합니다.
갱신 전에는 읽기를 종료하고 Chrome을 완전히 닫으세요. 재설치 후 Chrome 확장 목록에서 술술을 새로고침하고 읽던 페이지도 새로고침합니다. 같은 ID·설치 경로로 업데이트하면 로그인·설정이 유지됩니다. 다른 AI만 사용했다면 ChatGPT를 한 번 연결하세요.
스토어 공개 후 확장은 Chrome이 업데이트하지만 PC 연결 프로그램은 새 설치 파일로 갱신해야 합니다. 연결 프로그램 자체 자동 업데이트는 없습니다.
ZIP·소스에서 스토어 또는 포크 제품으로 바꾸면 확장 ID가 달라질 수 있습니다. 기존 확장을 제거하고 같은 배포자의 새 확장과 연결 프로그램을 설치하세요. ID가 바뀌면 번역 캐시·버튼 위치는 자동 이전되지 않습니다.

사용 한도
ChatGPT 계정의 Codex 이용 한도를 사용합니다. ChatGPT 대화의 잔여 횟수와 동일하다고 가정하지 마세요. API 키 입력과 유료 API 자동 전환은 없습니다.

모델과 Fast 모드
ChatGPT 설정 → 모델 설정에서 모델을 고르거나 직접 입력합니다. 기본값은 default(계정 기본 모델)이며 Fast 모드는 꺼져 있습니다. 모델 저장 후 연결 확인으로 계정에서 사용할 수 있는지 확인하세요.
Fast는 지원되는 모델에서 속도를 높이는 대신 사용량이 더 차감됩니다. 설정을 저장하면 번역을 원문으로 돌리고 일시중지하므로 페이지에서 이어 읽기를 누르세요.

저장된 번역
문단별 캐시를 사용해 같은 내용의 번역을 재사용하고 바뀐 문단만 요청합니다. 메뉴는 같은 출처(origin)에서, 본문은 같은 문서·제목·절에서 재사용합니다. 캐시는 번역 언어·모델·Fast 설정별로 구분하며 최대 약 3MB·1,500항목을 이 Chrome 프로필에 보관합니다. 설정의 저장된 번역 지우기로 삭제할 수 있습니다.

문제 해결
연결 프로그램을 찾지 못하면 설치 폴더에서 install.cmd를 다시 실행합니다. Mac은 설치 앱을 다시 실행합니다.
계정 연결 오류는 ChatGPT 설정 → ChatGPT 연결, 모델 오류는 모델 설정을 default로 저장한 뒤 연결 확인을 누릅니다.
설정 파일 오류는 Chrome을 종료하고 host/config.json의 providerSettings에 지정된 파일을 다른 이름으로 보관한 뒤 다시 실행하세요. 인증 파일의 내용은 공유하지 마세요.

삭제
Chrome 확장을 삭제하고 Windows는 uninstall.cmd, Mac 소스 설치는 bash uninstall.command를 실행하면 연결 등록이 해제됩니다.
Mac 설치 앱 사용자는 ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.sulsul.gemini.json을 제거하면 연결 등록이 해제됩니다.
로그인 데이터는 설치 폴더의 data/accounts/codex/profile에 남습니다. 이를 직접 삭제하면 술술의 Codex 로그인도 지워집니다. Mac 설치 앱의 기본 폴더는 ~/Library/Application Support/Sulsul/runtime입니다.
이전 버전의 로그인 데이터와 API 암호화 자료는 자동으로 삭제되지 않습니다. 해당 제공자의 계정 설정에서도 필요에 따라 연결을 해제하세요.
